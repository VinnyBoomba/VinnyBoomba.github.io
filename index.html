Watch Later Auto

Watch Later Auto is a private automation run by its account owner using Google Apps Script and YouTube Data API v3. It helps organize YouTube videos into a user-controlled playlist.

What it does

  • Checks YouTube channels and selected playlists for uploads.
  • Applies rules for titles, descriptions, duration, and other video attributes.
  • Adds matching videos to a private playlist authorized by the account owner.
  • Uses a Google Sheets spreadsheet to store configuration, processing history, and operational logs so previously processed videos are not repeatedly added.

Access and privacy

Only the account owner is intended to use this application. Access to Google and YouTube information occurs only after Google authorization. Permissions can be revoked through Google Account settings.
